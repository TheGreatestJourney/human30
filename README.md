# Human 3.0 Development OS

A mobile-first, installable progressive web app inspired by the Human 3.0 development framework.

## Run locally
Open `index.html` in a modern browser. Core features work locally; installability and offline caching require serving over HTTPS or localhost.

## Publish free
1. Upload the contents of this folder to a static host such as GitHub Pages, Cloudflare Pages, or Netlify.
2. Open the HTTPS URL on Android Chrome.
3. Use the browser menu > Install app / Add to Home screen.

## Features
- Four-quadrant dashboard with editable self-assessment scores
- Quadrant questionnaire and developmental orientation selectors
- Descriptive metatype snapshot
- Mission planning and AI-ready prompt generation
- Daily practice tracker and habit log
- Reflection journal
- Assessment history and 30/90/365-day review
- JSON export/import backups
- Local-first storage and offline service worker

## Important limitations
- Data is stored in the browser on the device. It is not automatically synced across devices.
- AI review prompts are generated for copying into ChatGPT or another AI assistant. This app does not contain an AI API or send your data anywhere.
- Scores, levels, and metatype are reflective aids, not validated psychological measurements or an official Dan Koe assessment.
